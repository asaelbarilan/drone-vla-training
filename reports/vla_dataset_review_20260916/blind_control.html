Do these models read the camera?

One question only. Every model answered the same 72 decisions twice: once with the real frames, once with every frame replaced by flat gray. If blinding a model does not change its answers, that model is not using the image, and its position in the direction-agreement table reflects its text prior. This page is not a flight benchmark.

Result

Changed counts how many of the 72 answers moved when the images were blinded — the direct measure of whether pixels reach the decision. Distinct is how many different answers a model produced across 72 different images. McNemar p tests the paired real-versus-gray accuracy difference; above 0.05 the difference is not separable from noise at this panel size.
