# Evidence matrix

Search date: 2026-09-10. 41 candidates screened; 24 primary works inspected at methods/results depth. Public resource availability is recorded separately from reproducibility.

| ID | Work | Mechanism established | Boundary / caution |
|---|---|---|---|
| onfly | [OnFly: Onboard Zero-Shot Aerial Vision-Language Navigation toward Safety and Efficiency](https://arxiv.org/html/2603.10682v1) | Two VLM roles, hybrid visual memory, semantic/depth refinement and goal-facing receding-horizon execution; Table III separates model and mechanism effects. | Author implementation remains unreleased; local clean-room implementation cannot claim exact reproduction. |
| spf | [See, Point, Fly: A Learning-Free VLM Framework for Universal Unmanned Aerial Navigation](https://arxiv.org/html/2509.22653v1) | RGB waypoint and intended step-size prediction are converted to movement; Table 2 compares interfaces under the same Gemini backbone. | Small/distant objects, prompt sensitivity and latency are acknowledged; local normalized stop rule differs. |
| fly0 | [Fly0: Persistent Metric Anchoring for Zero-Shot Aerial Vision-Language Navigation](https://arxiv.org/html/2602.15875v2) | Version 2 uses uncertain region grounding, relation-aware free-space goals and persistent metric anchors between semantic updates. | False semantic identity can remain geometrically stable; inspected public code predates v2 and is not verified equivalent. |
| vlmnav | [End-to-End Navigation with Vision-Language Models: Transforming Spatial Reasoning into Question-Answering](https://arxiv.org/html/2411.05755) | Depth/pose-based navigable action proposals are visually annotated; a separate call judges stopping. | ObjectNav SR 50.4% versus 12.9% without sliding reveals simulator dependence; not aerial validation. |
| pivot | [PIVOT: Iterative Visual Prompting Elicits Actionable Knowledge for VLMs](https://arxiv.org/html/2402.07872) | Iterative marked action candidates turn continuous action selection into visual question answering; navigation actions lifted with depth and capped at 1 m. | Multiple calls per action; limited action expressivity and imperfect zero-shot success. |
| typefly | [TypeFly: Flying Drones with Large Language Model](https://arxiv.org/html/2312.14950) | LLM MiniSpec plans call perception and control skills; detector-generated location/size/color descriptions support reasoning. | Detector and skill execution contribute to success; not raw-RGB-only VLM evidence. |
| aerialvln | [AerialVLN: Vision-and-Language Navigation for UAVs](https://arxiv.org/html/2308.06735) | Front-view RGB-D, explicit rotations and 4-DoF actions; separate stopped success and oracle success. | 20 m goal threshold and city-scale scenes differ from the local 2 m gate. |
| citynav | [CityNav: Language-Goal Aerial Navigation Dataset with Geographic Information](https://arxiv.org/html/2406.14240) | CityFlight uses real-city scan geometry and geographic information; 32637 human demonstration trajectories. | Geographic priors and long-distance task setup are not interchangeable with first-person local target pursuit. |
| openuav | [Towards Realistic UAV Vision-Language Navigation: Platform, Benchmark, and Methodology](https://arxiv.org/html/2410.07087) | Continuous 6-DoF trajectories and realistic flight modeling distinguish UAV navigation from discrete ground-agent conventions. | High-fidelity simulator/data/training burden; not an off-the-shelf prompt-only baseline. |
| openfly | [OpenFly: A Comprehensive Platform for Aerial Vision-Language Navigation](https://arxiv.org/html/2502.18041) | Multi-renderer aerial data and a trained keyframe-aware navigation agent with action decoding. | Keyframe mechanism is trained with navigation data; adding image history to arbitrary VLMs is not equivalent. |
| stmr | [Exploring Spatial Representation to Enhance LLM Reasoning in Aerial Vision-Language Navigation](https://arxiv.org/html/2410.08500) | Grounding DINO and Tokenize Anything produce depth-backed semantic/topological/metric grids for an LLM planner. | Separate visual experts and discretized metric maps supply structure missing from raw image prompts. |
| spatialvlm | [SpatialVLM: Endowing Vision-Language Models with Spatial Reasoning Capabilities](https://arxiv.org/html/2401.12168) | Spatial QA training data are synthesized with detection, depth and geometry to improve spatial reasoning. | Does not establish zero-shot aerial navigation; training and scene assumptions matter. |
| spatialrgpt | [SpatialRGPT: Grounded Spatial Reasoning in Vision-Language Models](https://arxiv.org/html/2406.01584) | Region-aware features and optional depth plus spatial training improve qualitative/quantitative spatial reasoning. | Region QA benchmark gains do not validate dynamic control or exact target stopping. |
| navid | [NaVid: Video-based VLM Plans the Next Step for Vision-and-Language Navigation](https://arxiv.org/html/2402.15852) | Historical/current visual tokens feed a trained RGB-only navigation model; navigation data scale materially affects results. | Uses 510k navigation samples, not generic VLM prompting; aerial transfer unverified. |
| navbench | [NavBench: Probing Multimodal Large Language Models for Embodied Navigation](https://arxiv.org/html/2506.01031) | Separates global alignment, temporal progress and local action comprehension from closed-loop execution. | Indoor/discrete navigation benchmark; correlation is not causal proof for C5. |
| blind | [Vision language models are blind: Failing to translate detailed visual features into words](https://arxiv.org/html/2407.06581) | Seven low-level geometric tasks expose failures on visually simple inputs; prompting does not reliably remove them. | Tested models and task generation differ from repaired Gemma; simple renderer difficulty is a hypothesis here. |
| vlnce | [Beyond the Nav-Graph: Vision-and-Language Navigation in Continuous Environments](https://arxiv.org/html/2004.02857) | Continuous execution removes navigation-graph assumptions and changes baseline behavior. | Ground-agent benchmark; transfer lessons concern evaluation assumptions, not UAV performance estimates. |
| lmnav | [LM-Nav: Robotic Navigation with Large Pre-Trained Models of Language, Vision, and Action](https://arxiv.org/html/2207.04429) | GPT landmark extraction, CLIP associations and trained ViNG navigation are linked through a topological graph. | Prior observations and learned navigation policy are load-bearing, despite no language-navigation fine-tuning. |
| vlmaps | [Visual Language Maps for Robot Navigation](https://arxiv.org/html/2210.05714) | Dense language-aligned image features are fused into 3D maps using RGB-D and odometry. | Mapping/localization and feature extraction are explicit; not a direct arbitrary-VLM pixel policy. |
| moka | [MOKA: Open-World Robotic Manipulation through Mark-Based Visual Prompting](https://arxiv.org/html/2403.03174) | Keypoint/grid marks select affordances and motion waypoints; evaluation separates reasoning from execution failures. | Manipulation evidence only; supports diagnostic methodology, not aerial navigation success. |
| geonav | [GeoNav: Empowering MLLMs with Dual-Scale Geospatial Reasoning for Language-Goal Aerial Navigation](https://arxiv.org/html/2504.09587) | Geographic landmark priors, hierarchical spatial representations and staged reasoning support aerial goal navigation. | Prior geographic information is absent in the current local task; code link points to CityNav resource, not verified GeoNav implementation. |
| openvla | [OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/html/2406.09246) | A VLM is trained on 970k robot demonstrations to predict 7D manipulation actions. | Trained manipulation action interface cannot be assumed to control a UAV zero-shot. |
| airanchor | [AirAnchor: Bridging Local and Global Spatial Information for Zero-Shot Aerial Vision-and-Language Navigation](https://arxiv.org/html/2609.08442) | Object anchors link local grounding and persistent scene memory; Qwen3.6-Plus plus A-star and four skills. | Released September 8 preprint; memory persists across episodes in a scene and needs cold-start accounting; simulation only. |
| vlfm | [VLFM: Vision-Language Frontier Maps for Zero-Shot Semantic Navigation](https://arxiv.org/html/2312.03275) | BLIP-2 semantic value maps rank geometric frontiers; target detection and PointNav/robot navigation execute movement. | Simulation PointNav trained for 2.5 billion steps; target visibility assumptions and detector false positives remain. |
