What this test establishes

The same SUPER implementation can leave this state and use a wider route when given one persistent destination. All 39 replans were accepted. The destination was supplied manually beyond the obstacle pair; the route was planned from onboard range observations.

At the restored instant, the original accepted destination was only 0.38 m from the drone. In this test it is 10.84 m away. This tests the combined destination-selection, depth-lifting and updating boundary; it does not isolate which part caused the original stall.

Conditions and limits

Same initial pose, velocity, map history, planner margins, controller and dynamics. Same fixed goal refreshed every second; 20 Hz control. No model/API calls. Policy, monitor and image-point verifier are bypassed for this manual metric-goal diagnostic.

The red inflation is derived from SUPER’s sparse range map, not true wall geometry. Nominal inflation is 1.8 m; the measured physical clearance can differ. This is a privileged diagnostic, not an autonomous mission success or a paper benchmark score.
